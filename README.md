# NumerOM Mobile

Публичная браузерная версия: https://dmitriimalahov-gif.github.io/numerom-app/

Этот репозиторий содержит только собранный интерфейс для iPhone, Android и браузера. Подписанные IPA/APK будут выпущены отдельно. Сервер пилота работает на компьютере владельца. Службы автоматически перезапускаются; приложение получает новый HTTPS-адрес из подписанного runtime-config.json без смены ссылки. Во время отключения компьютера серверные функции недоступны.

База пользователей, серверный код, ключи и пароли в этот репозиторий не включены.
