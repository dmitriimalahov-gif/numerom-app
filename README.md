# NumerOM Mobile

Публичная браузерная версия: https://dmitriimalahov-gif.github.io/numerom-app/

Этот репозиторий содержит только собранный интерфейс для iPhone, Android и браузера. Подписанные IPA/APK будут выпущены отдельно. Сервер пилота работает на компьютере владельца через временный HTTPS-адрес и зависит от его доступности.

База пользователей, серверный код, ключи и пароли в этот репозиторий не включены.
